# Product website

Mode: Persuade. Audience: developers using local coding agents. Confirmed action: understand capabilities and visit GitHub source. Independent static website; existing desktop behavior remains authoritative. Code-led implementation with existing icon, poster, video and actual Island component, no generated imagery or commercial claims.

## Direction contract

THESIS: Show the small desktop island doing its job, then connect attention, permissions and remote handling to time away from terminals.

OWN-WORLD: Inherit black capsule, system Chinese typography and semantic green from the product. Soft neutral light ground and sage demonstration surface; dark equivalents preserve hierarchy. Spacing separates content, thin dividers organize questions, understated controls keep the island focal.

STORY: Recognize supported agents, click real example sessions, learn approval and remote boundaries, then inspect source or download releases.

FIRST VIEWPORT: Two-column headline and live island demonstration at desktop; centered copy above the demonstration on mobile. The primary GitHub action accompanies the headline. Three scene tabs remain operable by keyboard. Sample data is labeled.

FORM: Product demonstration with supporting explanation, existing visual world. Surface seed 2ca0a103. The user's GitHub-first goal determines action hierarchy.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
